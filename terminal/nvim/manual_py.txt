本套 Neovim 設定提供一個輕量、直接且偏實用導向的 Python 開發環境，整合程式編輯、自動補全、型別提示、語法診斷與程式碼格式化功能，適合日常練習、小型腳本撰寫、課堂作業與基礎專案開發。

核心能力建立在兩個主要工具上。第一個是 pyright，負責 Python 語言伺服器功能，包括補全、型別分析、屬性提示與診斷資訊。第二個是 ruff，負責程式碼格式化，讓整份 Python 程式保持一致、整齊且可讀性高。整體體驗以快速輸入、即時提示與簡潔操作為核心，不需要離開編輯器即可完成大部分常見流程。

啟動方式是以 Neovim 開啟 .py 檔案，例如輸入 nvim test.py。進入檔案後即可開始撰寫程式碼。當輸入 Python 物件、模組名稱或方法呼叫時，補全系統會自動提供候選項目。這些補全內容來自 pyright 的分析結果，再由 nvim-cmp 顯示成清楚的選單介面。

補全功能支援自動彈出與手動觸發兩種方式。當輸入到適合的位置時，補全選單通常會自動顯示；若需要主動呼叫，則可使用 Ctrl + Space。補全清單中的內容可用 Tab 向下切換，Shift + Tab 向上切換，Enter 則用來確認並插入目前選中的項目。這項設計適合用在字串方法、列表方法、模組函式、類別屬性與一般變數相關提示上，可減少手動輸入並提高輸入效率。

例如當程式中出現一個字串變數，輸入 x. 之後，補全系統通常會列出像 upper、split、strip、find 等可用方法。這類補全不只是文字建議，也反映了目前變數的型別，因此在 Python 這種動態語言中尤其實用，能在撰寫時補足型別資訊不足的問題。

除了補全之外，本套設定也提供診斷資訊顯示。當程式中出現不相容操作、未定義名稱、可疑語法或型別衝突時，畫面會以自訂診斷符號標示相關位置。若需要查看詳細內容，可將游標移至目標位置並按下 K，畫面會開啟一個浮動視窗，顯示目前位置的診斷訊息。這種呈現方式讓錯誤提示不會過度干擾編輯畫面，同時保留快速查看細節的能力。

本套 Python 環境另一個重點功能是程式碼格式化。快捷鍵為 Space + f。觸發後，系統會先儲存目前檔案，再對該 Python 檔執行 ruff format，最後重新讀取檔案內容。這個流程可自動整理空格、括號、逗號、函式定義與整體排版風格，使程式碼維持一致的結構與視覺節奏。

例如原本程式碼若寫成較凌亂的形式，格式化後會自動調整成較標準、整齊的樣式。這項能力非常適合用於寫完一段函式、整理作業程式碼、統一專案風格或準備分享程式片段時使用。整體定位偏向快速整理，而不是重寫邏輯，因此它的價值在於讓程式碼輸出更乾淨，而非改變功能本身。

剪貼簿整合也已納入設定。Space + y 可將選取內容送入系統剪貼簿，方便將 Python 程式碼貼到瀏覽器、文件、作業平台或筆記工具中。這對於課堂提交、示範片段與整理說明文件都相當方便。

基本編輯體驗則維持 Vim 傳統操作。插入模式可用 i 進入，在游標後方插入可用 a，向下開新行可用 o。刪除一整行使用 dd，複製整行使用 yy，貼上使用 p，復原使用 u，重做使用 Ctrl + r。存檔為 :w，離開為 :q，存檔離開為 :wq。這些標準操作與 Python 撰寫流程自然結合，不需要額外記憶新的編輯方式。

在畫面配置方面，本套設定啟用了相對行號、四個空格縮排、真彩色顯示與 Treesitter 語法高亮。對 Python 而言，縮排本身就是語法的一部分，因此一致的空白設定與清楚的結構顯示非常重要。這些基礎設定可讓函式、條件判斷、迴圈與類別區塊更容易閱讀。括號與引號的自動配對功能也已啟用，可在輸入時自動補齊對應符號，提高流暢度並減少簡單輸入錯誤。

整體而言，這套 Python 環境的設計重點是把「開檔、輸入、補全、查看提示、整理格式」放進同一條順暢流程中。最核心的操作可濃縮為幾個按鍵：Ctrl + Space 用於手動叫出補全，Tab / Shift + Tab / Enter 用於操作補全選單，K 用於顯示診斷資訊，Space + f 用於格式化 Python 程式碼，Space + y 用於複製到系統剪貼簿。掌握這些操作後，Python 的日常撰寫流程就能保持簡潔、快速且一致。
